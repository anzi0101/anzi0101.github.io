# 个人主页 · 网络工程方向

一个单文件、零依赖、离线可用的个人求职主页。双击 `index.html` 就能打开，不需要装任何东西、不需要联网。

---

## 1. 怎么改成你自己的

打开 `index.html`，用 VS Code 或记事本，搜索 **【** 这个符号（中文方括号），凡是出现的地方都是待替换的占位内容：

| 位置 | 替换成 |
|---|---|
| 顶部导航、页脚、首屏终端块 | 你的真实姓名 |
| 首屏「关于我」那段 lead | 2~3 句自我介绍 |
| 教育背景 / 部队经历 / 证书卡片 | 真实信息（部队单位可脱敏写"某部"） |
| 技能条的三处 `熟练 / 掌握` 与百分比 | 按真实情况调，别虚标 |
| 页脚「手机 / 邮箱 / 现居」 | 真实联系方式 |
| 作品区第 ② ③ 张卡片 | 等你的第二、第三个作品做好后替换 |

替换完刷新页面即可，不用编译、不用打包。

信的位置需要留意的两点：
- **部队经历要写结果，不要只写职责。**「负责机房日常运维」不如「维护 12 台交换机与 3 套业务系统，任期内零非计划中断」。
- **不要写"熟悉"了却不举例。** 面试官一定会追问"你怎么排查的"，作品区就是用来接这一问的。

## 2. 页面里已经做好的两个真工具

**IPv4 子网计算器**：输入 `192.168.1.10/24`、`192.168.1.10/255.255.255.0` 或 `192.168.1.10 24`，输出网络地址、广播地址、可用主机范围、主机数、二进制掩码、规范化 CIDR。

**同网段判断**：输入两个 IP 和前缀长度，直接给出「同一网段 / 不同网段」及原因。这正是网络工程师考试和面试的高频题。

两个工具都是纯 JavaScript 写的，逻辑已验证过 `/0`、`/22`、`/30`、`/31`、`/32` 等边界情况。面试时你可以现场打开这个页面演示，比背概念有说服力得多。

## 3. 怎么发布出去（让 HR 能打开链接）

推荐 GitHub Pages，免费，链接稳定：

```bash
# 需要先装 Git：winget install --id Git.Git -e
cd 个人主页
git init
git add .
git commit -m "个人主页 v1"
# 在 GitHub 建一个名为 <你的用户名>.github.io 的仓库，然后：
git remote add origin https://github.com/<你的用户名>/<你的用户名>.github.io.git
git push -u origin main
```

推上去之后访问 `https://<你的用户名>.github.io` 就是你的主页。简历上写这个链接，比写"会用 HTML"有用。

如果暂时不想公开发布，也可以直接把 `index.html` 单文件发微信/邮箱给 HR，对方双击就能看。

## 4. 面试怎么讲这个作品

被问「这是你自己做的？」时，按这个顺序说，三句话讲完：

1. **为什么做**：备考网络工程师时天天算子网，手工算容易错，就写了个工具把它自动化。
2. **怎么做的**：纯前端，没有框架，把 IP 地址转成 32 位整数再做位运算，掩码用移位生成，所以 `/0` 和 `/32` 这种边界也不会算错。
3. **学到什么**：把课本上的"网络位 / 主机位"真正落到了位运算上，再没算错过；也顺手练了 HTML/CSS/JS。

> 重点是第 2 句——说出「转成整数再位运算」这个细节，就证明你真懂了，而不是套模板。
