① 子网划分计算器（本页内可试用）

纯前端实现的 IPv4 子网计算工具：输入 CIDR，输出网络地址、广播地址、可用主机范围、 主机数与二进制掩码，另附「两 IP 是否同网段」判断。无任何外部依赖，离线可用。

HTML · CSS · JavaScript · 无框架

② 抓包分析报告（在做）

一次 DNS 查询 / TCP 三次握手 / HTTP 请求的完整抓包，逐层标注报文字段， 配截图与结论，附 .pcapng 原件——面试时可现场打开演示。

Wireshark · pcapng · 文档

③ 批量巡检脚本（在写）

批量 Ping + 端口存活巡检，输出 Excel / HTML 报表。运维岗日常最常用的那件事， 写得清、讲得明，比证书更能证明手感。

Python · 自动化 · 报表
